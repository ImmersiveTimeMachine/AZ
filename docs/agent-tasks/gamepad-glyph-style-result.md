# Ограниченная проверка значков геймпада

По просьбе пользователя работу передали gpt-6-luna medium с ограничением объёма. Локальная LM Studio была без загруженной модели; новую модель не загружали.

Прочитаны CommonInput defaults BP_AZ_InventoryControllerData_Xbox, PS4, PS5. Xbox использует InventorySystemPro GamepadXboxOne T_XB1_*; PS4 использует MenuSystemPro GamepadPS4 T_PS4_*; PS5 использует тот же набор, кроме собственного T_FN_PS5_Create для левой специальной кнопки.

В этих наборах и InteractionEssentials/Textures/Input не найден однозначный набор квадратных дублей для замены. Найденный PS4 Square — обозначение кнопки, не квадратный стиль набора. Автоматические замены не производились, кнопки не переназначались. Унифицированный квадратный внешний Keycap уже сделан основным агентом. Создание нового полного набора glyph-арта отложено, чтобы не раздувать расход токенов без готовых исходников.
