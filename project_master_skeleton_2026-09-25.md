★ When the skeleton is referenced by ONLY that one mesh (the master), the commit takes the FullMerge path =
`RecreateBoneTree(mesh)`: the skeleton's ref pose is REPLACED by the mesh's (hero proportions, up to 6.6 cm off the MH
template pose). Skeletons shared by many meshes (metahuman_base_skel) take MergeAllBonesToBoneTree = pose kept.

`UpdateRefPoseTransform(rawIndex, ...)`, then saving. It matters: FSkeletonRemapping (compatible skeletons,
SkeletonRemapping.cpp) builds rotation deltas and translation scaling from BOTH skeletons' ref poses - identical poses =
identity (bit-exact) playback. `az_master_skeleton.py verify` catches it. Any future bone add on the master needs the
restore again. Harness note: one run compiled fine but its static init never fired (no log) - log the init entry and
