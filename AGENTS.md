# Project rules

- Do not add automated tests, including Unreal Automation Framework tests, unless the user explicitly asks for them. A general request to implement, fix, or validate a feature does not authorize adding automated tests.
- Ask the user before starting PIE or running tests in Unreal Editor. By default, let the user perform editor testing, then read the logs.
- NEVER rewrite git history or delete files git does not track: no `git filter-branch`, `git filter-repo`, BFG, `git clean` (except `-n` dry runs), and no rebase/reset that drops commits which added files. Stripping paths from history deletes those files from disk: on 2026-09-22 this erased the hero face mesh, all of `UI Design/` and a Fab plugin (731 files). If a push is blocked by file size, stop and tell the user; do not rewrite anything. If a rewrite is ever unavoidable, the user runs it himself, after the affected paths are copied outside the repo and verified. Keep the branch `backup/pre-bigfile-strip-2026-09-22`: it is the only other copy of those files.
