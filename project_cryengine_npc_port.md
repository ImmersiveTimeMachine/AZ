- Clip source = Unreal export of /Game/Zombie_01/Animations/Root (150) via `tools/npc/ue_export_chalkie_clips.py`, not the MotionBuilder FBX (Y-up, root -90 prerotation).
- UE mesh export puts an identity Null above `root`; RC MarkPath makes every ancestor a joint -> remove it (`fbx_chalkie_prepare.py mesh`). RC forward_up_axes for UE exports = "+Y+Z" (zombie faces -Y in FBX). Morph targets become `*_blendWeightVertex` joints -> export mesh without morphs.
- Own FBX writer must keep the original footer id (FBX SDK checks it vs CreationTime) and pad file length to 16, else RC says "File is corrupted".
- Git Bash mangles RC `/switch` args -> `MSYS_NO_PATHCONV=1`.
- RC i_caf->caf: pass the clip path RELATIVE to /sourceroot (absolute path gets glued onto the root). Unreal FBX anim export adds one held key at the end -> give RC endFrame = length*30. animevents times are normalized.

A PE_LIVING entity's post-step event writes back the orientation from the start of its threaded step (half of every turn lost) -> keep an own yaw and re-apply it each frame. Idle clips swing their root (Idle_3 up to 173 deg) and leak into one-shot blends -> Mannequin anim flag FullRootPriority (= CA_FULL_ROOT_PRIORITY, Unreal "root motion from montages only") on one-shots + Full root motion only while the action is Installed.
